# extera Desktop — состояние работ

Обновлено: 2026-11-13. Этот файл читает новый чат вместо всей прошлой переписки.

## Что это
Перенос exteraGram (функции + система плагинов на Python) на ПК на базе Telegram Desktop 7.3.5 (слой API 232, как в exteraGram 13.1.1).
Репозиторий: `tnt-cat/exera-desktop`, рабочая ветка `exg`. Этот файл лежит в ветке `status`.

## Правила пользователя
- Отвечать коротко, с главного: пользователь читает с телефона, новичок, код сам не пишет.
- Ничего не придумывать (названия, классы, функции, поведение). Чего нет в файлах — сказать и спросить.
- Сборку в облаке запускать только по слову «собери». Никаких задач по расписанию без просьбы.
- API_ID и API_HASH не писать в чат, они в секретах репозитория.
- Коммиты по `AGENTS.md`: короткая тема, без строк Co-Authored-By.
- В контекст и память проекта ничего не добавлять без согласия.
- Экономить лимит: один чат — один этап, замечания пачкой.

## Сборка
- Только GitHub Actions, файл `.github/workflows/exg-win.yml`, запуск вручную (workflow_dispatch) на ветке `exg`. Около 75 минут.
- Последняя успешная сборка: коммит `2f65299`.
- Ещё ни разу не собирались: иконка (`5b89cfc`), переименования (`b6edec7`), описание (`f6c02d1`), система плагинов (`174a841`), сверка SDK (`994468f`). Первая сборка может упасть на ошибке компиляции.
- Архив сборки: `extera.exe` + папки `python` (Python 3.11) и `extera` (движок). Распаковывать целиком, поверх старой папки; вход хранится в `tdata` рядом с exe.

## Версия
`AppExteraVersionStr` в `Telegram/SourceFiles/core/version.h`, сейчас `0.0.1`. Показывается как `7.3.5 / 0.0.1`. Поднимать на 0.0.1 с каждой сборкой.

## Что сделано
- Название «extera Desktop», иконка с котиком, описание «неофициальная сборка exteraGram от vixn_n».
- Движок плагинов на Python: `extera/sdk` (тесты: `extera/tests/test_engine.py`, `test_bridge.py`).
- Встраивание в программу: `Telegram/SourceFiles/extera/` — загрузка `python311.dll` при старте, мост C++ ↔ Python, перехват отправки сообщения, тосты, диалоги, отправка текста.
- Окно «Плагины» (боковое меню и настройки): список с пометкой Работает / Частично / Не работает / Не для ПК, страница плагина, настройки, установка из файла, удаление, журнал.
- SDK сверен с настоящими сигнатурами exteraGram 1.4.6.3, расхождения исправлены. Остаток сверки пользователь попросил не делать.

## Чего плагины пока не могут
Запросы к серверу Telegram, реакция на входящие сообщения, отправка файлов, пункты в меню чата и сообщения, Android-интерфейс, формат Elyx.

## Этапы дальше (каждый — отдельный чат)
1. Окно плагинов как на телефоне: пользователь пришлёт скрины (список, страница плагина, окно установки). Установка по нажатию на файл `.plugin` в чате, пометка статуса в окне установки.
2. Сборка, исправление ошибок компиляции, замечания после проверки.
3. Кнопка «Обновить».
4. Запросы плагинов к Telegram + окно «Подтвердите действие» (в exteraGram это `SensitiveRequestConfirmation`: платежи, управление чатами, вход в аккаунт; проверку делать в C++).
5. Функции exteraGram по списку.
