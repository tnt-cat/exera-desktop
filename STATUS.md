## #база
- Цель: перенести exteraGram (Android-клиент Telegram: функции + плагины на Python) на ПК.
- Основа: Telegram Desktop 7.3.5 (C++/Qt 6). Выбрана, потому что слой API 232 совпадает с exteraGram 13.1.1; в 7.4 уже 233.
- Название программы: extera Desktop. Автор сборки в описании: vixn_n.
- Репозиторий: `tnt-cat/exera-desktop` (форк telegramdesktop/tdesktop, открытый).
- Ветки: `exg` — рабочий код; `status` — только этот файл; `dev` — ветка по умолчанию от Telegram, не трогаем.
- Источники знаний об exteraGram: два документа проекта (`Main`, `API`) и файл `Full classes` (10 МБ, все классы; пользователь прикладывает при необходимости).
- Компьютер пользователя: старый ноутбук, Windows 10, 4 ГБ памяти — собирать на нём нельзя.

## #сборка
- Только GitHub Actions: `.github/workflows/exg-win.yml`, запуск вручную (workflow_dispatch) на ветке `exg`. Около 75 минут, библиотеки берутся из кеша.
- Сборка отладочная (Debug): exe 565 МБ, архив 146 МБ.
- Последняя успешная сборка: коммит `2f65299`.
- Ещё не собирались: `5b89cfc` иконка, `b6edec7` переименования, `f6c02d1` описание, `174a841` система плагинов, `994468f` сверка SDK. Первая сборка может упасть на ошибке компиляции.
- В начале сборки скачивается Python 3.11.9 (embeddable), ставится `requests`, прогоняются тесты движка.
- Архив: `extera.exe` + папки `python` и `extera`. Распаковывать целиком в постоянную папку, новую сборку — поверх старой. Вход хранится в `tdata` рядом с exe. Запуск прямо из zip не подходит.

- Показывается как `7.3.5 / 0.0.1` в боковом меню и в «О программе»; архив сборки называется `extera Desktop 0.0.1`.

## #код
- `Telegram/SourceFiles/extera/extera_python.*` — загрузка `python311.dll` из папки `python` рядом с exe, вызовы в Python. Сборка от Python не зависит.
- `Telegram/SourceFiles/extera/extera_plugins.*` — сторона программы: журнал, тосты, диалоги, отправка текста, перехват отправки.
- `Telegram/SourceFiles/extera/extera_plugins_box.*` — окно «Плагины».
- Точки врезки: `ApiWrap::sendMessage` (перехват отправки), `Core::Application::run` (запуск движка), `settings_main.cpp` и `window_main_menu.cpp` (пункт «Плагины»).
- `extera/sdk/` — движок и SDK на Python; `extera/tests/` — тесты (`test_engine.py`, `test_bridge.py`).

## #движок
- `extera_engine.py` — загрузка плагинов, хуки, меню, настройки. `extera_bridge.py` — единая точка `call(имя, json)` для программы. `extera_scan.py` — разовая проверка плагина при установке.
- Java-импорты плагинов не падают: класс с аналогом на ПК подменяется, остальные становятся заглушками, которые ругаются только при использовании.
- Плагины лежат в `extera/plugins` рабочей папки, настройки — в `extera/data`.
- Умеют: перехват и изменение отправляемого текста, команды, тосты, диалоги, отправка текста с разметкой, копирование, открытие ссылок, свои настройки, пункты главного меню (показаны в окне «Плагины»).
- Не умеют: запросы к серверу Telegram, входящие обновления, отправка файлов, пункты меню чата/сообщения/профиля, перехваты Java-методов, Android-интерфейс, формат Elyx.

## #окно-плагинов
- Открывается из бокового меню и из настроек.
- Список: название и пометка статуса справа. Нажатие открывает страницу плагина: включение, описание, причина пометки, настройки (переключатель, выбор, ввод, текст), удаление.
- Кнопки: установить из файла, открыть папку плагинов, скопировать журнал.
- Пользователь хочет вид как на телефоне и установку по нажатию на файл `.plugin` в чате с пометкой статуса до установки. Ждём скрины.

## #статусы
- Работает — плагину хватает того, что есть на ПК.
- Частично — есть перехваты Android-методов или классы Android-интерфейса.
- Не работает — внутри скомпилированный Android-код или ошибка в коде.
- Не для ПК — про функции телефона (камера, кружки, виджеты и т. п.). Такие и «Не работает» при установке выключены.
- Отбор «не для ПК» автоматический и грубый.

## #sdk
- Образец: SDK плагинов exteraGram 1.4.6.3, Python 3.11.
- Сверено с настоящими сигнатурами из документа `API`: 18 модулей, расхождения исправлены. Из 105 имён SDK, которые используют реальные плагины, есть 87; остальных 18 нет и в настоящем SDK.
- `extera_utils.classes` (создание Java-классов) — только заглушки, это чисто Android.
- Точные правила разметки `parse_markdown` в файлах не описаны; принимаются и `*жирный*`, и `**жирный**`.
- Не проверено (пользователь попросил остановиться): аргументы методов Android, часть поведения движка по описанию.

## #статистика
- Просканировано 584 плагина из 13 каналов (сканер — отдельный плагин для телефона).
- По сложности: 4% только верхний API, 6% только помощники, 23% Android-интерфейс, около 50% интерфейс + перехваты Java, 16% со встроенным dex.
- После отбора: 94 с dex, 59 только для телефона, 430 остаётся.

## #безопасность
- В exteraGram есть «Подтверждение чувствительных запросов» (`com.exteragram.messenger.security.SensitiveRequestConfirmation`, `SensitiveRequestSheet`, `SensitiveRequestSwitch`).
- Окно снизу: «Подтвердите действие», аккаунт, название запроса, «Разрешить» / «Отклонить».
- Категории: платежи, управление чатами, вход в аккаунт (пример: `auth.acceptLoginToken`).
- Список защищённых запросов спрятан в нативном коде, в файлах его нет.
- На ПК делать вместе с запросами плагинов к Telegram, проверку — в C++, чтобы плагин не обошёл.

## #обновление
- Пользователь хочет кнопку «Обновить». Предложено два варианта, выбор не сделан.
- Вариант 1: сборки выкладываются в Releases, в программе кнопка «Проверить обновления» (скачать, заменить, перезапустить).
- Вариант 2: `update.bat` рядом с exe.
- Учесть: Releases открыты всем, API-ключи зашиты в exe; архив 146 МБ на каждое обновление.

## #ресурсы
- Из Android нельзя взять готовые кнопки и окна (другой код отрисовки). Можно взять иконки, тексты, цвета, размеры, анимации.
- В имеющихся файлах только названия иконок и строк. Для настоящих нужен APK exteraGram 13.1.1 (129 МБ) или папка `res`.
- Перед тем как класть чужие иконки в открытый репозиторий, проверить лицензию exteraGram.

## #скрины
- Пока описан один: окно «Подтвердите действие» (см. #безопасность).
- Нужны: список плагинов и путь к нему в настройках, страница плагина с настройками, окно установки из чата.
